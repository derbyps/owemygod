# OweMyGod Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A dark-mode PWA that tracks money friends owe you, reads their replies with a Tinker-fine-tuned Qwen3-8B, drafts gentle→firm WhatsApp reminders, and pushes a 09:00 daily summary.

**Architecture:** One FastAPI app on Render (Starter + disk) with SQLite, an in-process daily job, Web Push, and server-rendered HTML. The model only translates (reply → date expression; level → message with placeholders); plain Python resolves dates, runs the schedule and fills in facts. Training/eval scripts mirror BoldPrint (`../boldprint/train`, `../boldprint/eval`) and run on the user's machine.

**Tech Stack:** Python 3.12, FastAPI, Jinja2, sqlite3 (stdlib), pydantic 2, openai (Tinker OpenAI-compatible endpoint), pywebpush, tinker 0.33.1 + tinker-cookbook 0.5.7, pytest, matplotlib.

**Spec:** `docs/superpowers/specs/2026-10-24-owemygod-design.md`

## Global Constraints

- Deadline: 2026-10-25 23:59 PDT (= 2026-10-26 14:59 WITA). Training tasks (2–4) come first so Tinker runs while the app is built.
- Tinker's API is unreachable from Claude's sandbox: Claude writes and dry-runs; **the user runs every Tinker command** and pastes output.
- Tinker spend caps: SFT ≤ $1.00, RL ≤ $1.20, eval ≤ $0.30; total ≤ $3. Base model `Qwen/Qwen3-8B`, renderer `qwen3_disable_thinking`, LoRA.
- The model never receives names, phone numbers or amounts.
- English UI. Currency per debt, dropdown **Rp / $** only: IDR shown as `Rp150k`, `Rp1.2jt`, `Rp1.25jt`; USD as `$40`, `$12.50`. Amounts stored as integer minor units (rupiah / cents). Dates in the user's timezone (`Asia/Jakarta` default, author `Asia/Makassar`).
- Daily push once per user per day at/after 09:00 local; at most one push per day; none if nothing is due.
- Never two reminders within 3 days. After 3 firm reminders with no reply/payment → status `talk`, no more reminders until resumed.
- Visual: dark mode; Purple `#9D4EDD` primary actions, Yellow `#FFC300` remind-today + amounts, Orange `#FF6B35` promised-today/firm/LUNAS stamp, Teal `#0F4C5C` surfaces/borders only (never text). Kasbon-book motif. No gradients, glassmorphism, ✨ icons or chat bubbles.
- Public demo/post use fictional people only. Commit messages end with the session attribution lines.

## Review Focus

1. **Month edges:** "tanggal 31" in a 30-day month, payday 25 already passed, "akhir bulan" on the last day → clamp to month end / roll to next month (tests in Task 1).
2. **Server in UTC, user in WITA:** the daily job must fire after 09:00 *local*, exactly once per local date, across restarts (tests in Task 10).
3. **Money typed loosely:** "150rb", "150k", "Rp 150.000", "1,5jt", "1.2jt" all parse; garbage is rejected with a form error, not a 500 (tests in Task 6).
4. **Model output junk:** prose around the JSON, `<think>` blocks, unknown `type`, missing `when` for a promise → fall back to rules and say so in the UI (tests in Tasks 1 and 8).
5. **Phone formats:** "0812-3456-789", "+62 812…", "62812…" → `62812…` for `wa.me`; empty → contact picker link (tests in Task 8).
